# 第 6 章 · 蒸馏进阶：让大模型当评分老师（一次诚实的失败）

第 4 章的微调用的是数据集自带的二元标签。这一章问一个自然的问题：**如果让一个前沿模型当老师，按四级评分尺给每对 (query, passage) 打概率分布，学生模型会不会学得更好？**

实测答案：**不会——三种配置全部退步**。这是一次值得完整复盘的失败，因为它排除掉的路径和它照亮的一样多。全部代码与数据在仓库里（`scripts/distill_generate.py`、`scripts/train_v2.py`、[DISTILLATION-NOTES](../../DISTILLATION-NOTES.md)）。

## 一、评分尺与教师

评分尺冻结自模式库的四级 rubric（与基准 score-zh 变体同一把尺）：

```
irrelevant  不相关（离题）
related     主题相关但未回答问题
partial     部分回答了问题
answers     直接且完整地回答了问题
```

教师：deepseek-v4-flash，每查询一次调用评完整个池（10 段），输出 10 个概率分布的 JSON 数组。

## 二、成本工程：¥56 → ¥8 的三步

这是本章附赠的一课——蒸馏的第一道坎往往不是质量而是账单。

| 手段 | 效果 | 备注 |
|---|---|---|
| 池化调用（10 段/调） | 调用数 ×1/10，系统提示词摊薄 | 还让教师看见完整池做相对评分 |
| `thinking: disabled` | 输出 token ×1/40 | v4-flash 是推理模型，推理通道默认烧 token——先探测再全量 |
| 谷时执行 | 输入 ¥2/M → ¥1/M | 定价分峰谷，跑量前查表 |

加上干跑纪律（先 20 条看解析成功率与成本预估）、熔断（失败率 >2% / token 超限即停）、断点续传（追加落盘），全量 **17,390 条判断零失败，~¥8**。

## 三、教师很聪明（这恰恰是故事的反讽之处）

教师自己的判别力用我们的协议量出来：**期望分分离 AUC ≈ 0.716——正好落在 hosted Jev 的区间（0.714-0.718）**。信号在教师那里是存在的、且是 Jev 级的。

## 四、但学生蒸不动

| 配置 | nDCG@5 | 对 v0.1 配对差 |
|---|---|---|
| v0.1（二元直接监督） | 0.488 | — |
| v0.2 纯蒸馏 | 0.428 | −0.060 [−0.106, −0.018]（显著） |
| v0.2.1 混合 w=0.5（软 CE + 硬标签辅助 BCE） | 0.430 | −0.057（显著） |
| v0.2.1 混合 w=1.0 | 0.428 | −0.060（显著） |

软标签确实干成了一件事：概率解压了（正例期望分均值 0.114 → 0.386，v0.1 的"概率贴着类先验"问题被修复）。但判别力不升反降（AUC 0.630 → 0.608-0.613）。第 3 章的从零模型（0.440，直接监督）也压过了全部蒸馏头——**教训跨弧线一致**。

## 五、为什么：三条机制

1. **指标的监督已经在数据里**。nDCG 对 gold 标签计算，BCE 直接优化 gold 标签。教师四级尺与 gold 的 argmax 吻合率 81.8%——剩下 18%（多数是 rubric 比 gold 更细，比如"部分回答"）对**这个指标**而言就是标签噪声。
2. **监督路径变弱了**。v0.1 的 BCE 直接压在分数 logit 上；蒸馏的梯度要穿过四级分布；混合版的辅助 BCE 又是作用在 softmax 期望分这个**派生标量**上——"直接信号"并不直接。权重 0.5→1.0 结果几乎不动，说明瓶颈在路径不在权重。
3. **学生有容量天花板**。教师的 0.716 住在前沿模型读原文的能力里；学生读的是冻结 bge-small-zh 的特征。v0.1 已经把这份特征里的排序信号榨得差不多了。

## 六、配方（如果要带走一句话）

- **gold 标签存在且就是你的指标时：直接监督，不要蒸馏。**
- 蒸馏的正确使用场景：目标行为的标签**不存在**（评分级、风格、复杂问题形态），或你需要可解释的分级输出且愿意付排序代价。
- **教师信号好 ≠ 蒸得动**：先小规模验证"学生吃不吃得下"，再花全量的钱。

教师判断本身是独立有价值的资产——17,390 条四级判断已作为数据集发布（[cnfeichen/t2reranking-4level-judgments](https://huggingface.co/datasets/cnfeichen/t2reranking-4level-judgments)），供阈值研究、rubric 分析、无 gold 场景的弱监督使用。
