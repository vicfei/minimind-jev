# 第 0 章 · 决策模型不是聊天模型：System One 心智模型

## 一句话

聊天模型生成文本；决策模型回答**类型化的问题**——给定状态和一个问题，返回选项、分数或概率，附带校准的置信度，一次前向，零个生成 token。

```
状态:  "查询：量子计算的基本原理
        段落：量子计算利用量子叠加与纠缠对信息编码……"
问题:  Noul("仅凭该段落能回答该查询吗？")
回答:  { "noul": 0.087 }        # 一个数，不是一段话
```

这就是 [Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)（TypeSafe 的 System One 模型）的形态，也是本教程要从零造出来的东西。

## 为什么它值得单独一类

- **输出有界**：答案只能在代码给定的选项/刻度内，模型幻觉不出一条控制指令。错误只能错在"选错了"，不能错在"说了不该说的"。
- **概率即特性**：好的决策模型返回的是校准概率——0.7 意味着十次里对七次。这让上层代码可以做选择性预测（不确定就不动作）。
- **一次前向**：没有自回归解码，延迟和成本天然低一个量级。

## 为什么用"中文重排"当入门任务

三个理由，都很实际：

1. **监督信号现成**：T2Reranking 数据集自带"这段能否回答这个查询"的标注，不用人工标注，也不用裁判模型。
2. **任务本身就是 Noul**：「仅凭该段落能回答该查询吗？」——一个二值判断，正是最简单的类型化问题。
3. **评测协议现成**：[jev-rag-zh-benchmark](https://github.com/vicfei/jev-rag-zh-benchmark) 提供同样本、同指标、同置信区间的对比，你的模型和 hosted Jev、BM25 站在同一条起跑线上。

## 我们要造什么（以及终点长什么样）

三个模型，一条弧线：

| 版本 | 做法 | nDCG@5（n=100，95% CI） | 训练成本 |
|---|---|---|---|
| **v0.1** | 冻结 bge-small-zh + 从零训 66 万参数决策头 | **0.488** [0.417, 0.559] | GPU 3 分钟 / $0 |
| **v0.2** | 蒸馏：让前沿教师按四级评分尺打软标签 | 0.428 [0.359, 0.495] | 教师 API 约 ¥8 |
| **v0.3-lite** | 完全从零：自有词表 + 1.5M transformer | **0.440** [0.372, 0.509] | 纯 CPU 3.5 小时 / $0 |
| （参照）hosted Jev 1.13 | — | 0.546 [0.481, 0.611] | — |
| （参照）BM25 | — | 0.413 [0.353, 0.477] | — |

想看这个架构在生产管线里的样子？[JevAny](https://github.com/SimpleJev/JevAny) 的 [agent 回路演示](https://simplejev.org/JevAny/index.html#case-library)录了三段双人对跑——左边 LLM-only、右边 LLM + Jev：WebShop 里 Jev 从菜单选项中选出正确的颜色/尺码（5 步 vs 9 步）；FrozenLake 里一次 LLM 规划后 Jev 逐状态比较四个方向（1 次调用 vs 4 次）。这就是本教程第 0 章讲的"模型提议、Jev 答问、代码组合裁定"合同的运行画面。

先把丑话说完：**三个 homemade 模型没有一个打赢 hosted Jev 的点估计**。但读法要准确——

- v0.1 对 hosted Jev 的配对差是 −0.059 [−0.040, +0.157]，**置信区间含零**：在这个样本量下两者统计不可分；
- v0.1 对 BM25 配对差 +0.075 [+0.002, +0.154]，**区间不含零**：真赢；
- v0.3-lite 用 1.5M 参数、3.5 小时 CPU、零预训练底座，跟 BM25 和 v0.1 都打成了统计平手。

换句话说：**3 分钟 GPU 训练的头摸到了 hosted 模型的噪声范围；纯 CPU 从零的 1.5M 摸到了 BM25 之上**。这两个数字就是本教程的卖点——白盒拆开看，规模与预训练到底贡献了什么，第 5 章逐行读表。

## 诚实的一问：为什么不直接读 LLM 的 logit？

2026 年 10 月有篇论文（[Releasing the Inner Jev](https://arxiv.org/abs/2610.17205)）证明：现成开源指令模型读末位 token 的选项字母 logit，零训练就能逼近 Jev。既然如此为什么还要从零训？因为目的不同——

- 那条路线给你一个**能用的答案**；本教程给你一个**能拆开看懂的系统**：词表怎么训、注意力怎么算、损失怎么选、概率为什么贴着先验、蒸馏为什么失败。这些知识迁移到任何决策模型上。
- 从零路线还有一个实际收益：**1.5M 参数、6MB 检查点、CPU 可训**——边缘部署和二次开发没有依赖。
